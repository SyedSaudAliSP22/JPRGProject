# Student_System

1. Do not open the `Student_System` folder directly in VScode, Instead open the `JPRG_DITFT2A03_CA2_Tharik_Ali` folder above

2. When `loadStudentsFromFile()` is used, make sure the relative path of the txt file, `"Student_System\\students.txt"` is entered in its parameter.

3. Compile for Student side
    - `javac Student_System/*.java .\Student_System\Frame\*.java .\Student_System\Model\*.java .\Student_System\Panels\*.java .\Student_System\Utilities\*.java`

4. To Run Student side
    -  `java .\Student_System\App.java`

5. To Run Admin side
    -  `java .\Student_System\AppAdmin.java` (This is my Teammates Side)
